# QUIC TLS certificates for local testing

The QUIC listener requires a TLS certificate trusted by the viewer. The fallback
self-signed certificate generated by `run-all-in-one.sh` is useful for server
startup only, but viewers will commonly reject it with `unknown ca`.

For local viewer testing, use `mkcert` on the host that runs the viewer.

## Windows host / WSL repo

Install and trust the local CA on Windows:

```powershell
choco install mkcert
mkcert -install
```

Generate a certificate into this repository:

```powershell
cd C:\new\backend
mkdir docker\quic-test\certs
openssl req -new -newkey rsa:2048 -nodes -keyout docker\quic-test\certs\quic-key.pem -out $env:TEMP\opensim-quic.csr -subj "/CN=localhost" -addext "subjectAltName=DNS:localhost,IP:127.0.0.1,IP:::1"
mkcert -csr $env:TEMP\opensim-quic.csr -cert-file docker\quic-test\certs\quic-cert.pem
```

The CSR step gives the certificate a `CN=localhost`, which OpenSim's HTTPS
listener validates at startup. Direct `mkcert localhost 127.0.0.1 ::1` creates a
valid SAN certificate, but OpenSim also checks the common name.

Then restart the Docker test server:

```bash
cd /mnt/c/new/backend
docker compose -f docker-compose.quic-test.yml down
docker compose -f docker-compose.quic-test.yml build opensim-all-in-one
docker compose -f docker-compose.quic-test.yml up -d opensim-all-in-one
```

On startup, logs should include:

```text
[all-in-one] Using provided QUIC TLS certificate from docker/quic-test/certs/quic-cert.pem
```

The generated files are copied to:

```text
bin/SSL/quic/quic-cert.pem
bin/SSL/quic/quic-key.pem
```

and OpenSim uses:

```ini
CertificatePath = "SSL/quic/quic-cert.pem"
PrivateKeyPath = "SSL/quic/quic-key.pem"
```
