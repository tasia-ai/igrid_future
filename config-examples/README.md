# Config examples

This folder collects **source-only** configuration samples for Tranquillity features. It is text-only and includes no binaries.

## Index

- `Robust.ini.example`: Combined Robust configuration for Tranquillity add-ons.
- `OpenSim.ini.example`: Combined region/simulator configuration for Tranquillity add-ons.
- `profile-badges/`
  - `Robust.ini.example`: User profile service configuration for `customer_type` storage.
  - `Region.ini.example`: Region-side `SetBadge` capability settings.
- `marketplace/`
  - `Robust.ini.example`: Notes for Robust (no configuration required for `/send`).
  - `Region.ini.example`: Enable the marketplace `/send` add-on and set its required password.
- `addons/README.md`: Overview of shipped add-on modules and where to enable them.
