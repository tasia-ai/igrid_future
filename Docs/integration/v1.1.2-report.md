## Candidate changes

1. `873681142c` — imported upstream v1.1.2 server-side baking commit
   `90878ce438` (COF clothing authority, careful unresolved-link handling,
   ordering updates, and removal regression tests).
2. `d6f1fcf39a` — added a PostgreSQL UserAccount version 7 forward repair and
   SQLite version 4 DisplayName/NameChanged columns for upstream PR #411.
   PostgreSQL v7/v8 now inspect actual column definitions, normalize blank/null
   timestamps and display/country fields, guard length/type conversion, retain
   `UserCountry`, and reject malformed or out-of-range values rather than
   truncating them.
3. Ported group-owned and group-managed estate authority from
   `test-2026-09-28` (`75391417f65a`) to the modern `Source/` tree. This adds
   group owner-role and selected manager-role checks, a 30-second membership
   cache, estate-console configuration, and estate owner-group/manager-role
   persistence migrations for MySQL, PostgreSQL, and SQLite.
4. Added offline estate authority regression tests and an integration-branch
   GitHub Actions workflow for Linux and Windows x64 solution builds plus
   framework and ServerSideBaking tests. The workflow intentionally has no
   database service and does not launch a grid.
5. Added `SkiaSharp.NativeAssets.Linux` as a direct dependency of the shared
   baking library so its Linux native binary is copied to test output.
6. Added forward EstateStore repair versions PostgreSQL 18, MySQL 40, and
   SQLite 15, plus provider startup schema guards. These account for the old
   I-Grid v16/v38/v13 group-authority histories colliding with upstream
   Experience-table histories; the guards preserve an existing owner-group
   column and manager-role rows.
